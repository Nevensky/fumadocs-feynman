# fumadocs-feynman documentation

The documentation site of [fumadocs-feynman](../README.md), built with [fumadocs](https://fumadocs.dev) on Next.js.
It uses the package from this repository (`"fumadocs-feynman": "file:.."`), so the docs always show the code
beside them.

## Develop

```bash
npm install     # here, or npm run docs:install at the repository root
npm run dev     # http://localhost:3000
npm run gen     # regenerate the Examples pages and the template reference from the package
npm run check   # compile every page with the MDX compiler and the feynman plugin, in strict mode
npm run build
```

## Content

- `content/docs/` holds the pages; each folder's `meta.json` orders the sidebar.
- `content/docs/examples/` and `content/docs/reference/templates.mdx` are generated by `scripts/gen-pages.mjs`.
  Edit `examples/examples.js` or `src/templates.js` instead, then run `npm run gen`. CI checks that they are current.
- The site registers the `Feynman` component and fumadocs-ui's Tabs, Steps, TypeTable, Accordions and Files for MDX
  in `components/mdx.tsx`, and adds the remark plugin in `lib/source.ts`.

## Deploy

- **GitHub Pages:** `.github/workflows/docs.yml` builds a static site on every push to `main` and publishes it.
  Enable it once in the repository settings: Pages → Build and deployment → Source: GitHub Actions (not "Deploy
  from a branch", which runs GitHub's own Jekyll build over the repository and fails on the MDX pages). The build
  sets `DOCS_EXPORT=1` (a static export into `out/`), `NEXT_PUBLIC_BASE_PATH=/<repository>` and
  `NEXT_PUBLIC_SITE_URL=https://<owner>.github.io`. Search runs in the browser on an index built at build time.
- **A Node host** (Vercel or similar): `npm run build` and `npm start`, with `docs/` as the project's root.
