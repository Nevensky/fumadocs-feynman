A template draws a whole diagram, or an equation, from one line: its name, then options written `key=value` (text in double quotes when it has spaces or TeX), and flags written as bare words. Options that are not listed are an error that names the ones there are. [Using templates](/docs/guides/templates) shows how to combine a template with statements of your own.
