## Citing

If you use fumadocs-feynman in a paper, a thesis or published notes, please cite it:

```bibtex
@misc{golenic_fumadocs_feynman,
  author       = {Goleni{\'c}, Neven},
  title        = {fumadocs-feynman: {F}eynman diagrams for fumadocs},
  howpublished = {\url{https://github.com/Nevensky/fumadocs-feynman}},
  year         = {2026},
  note         = {Version 0.1.0}
}
```

The entry prints in full with biblatex and with classic BibTeX styles such as apsrev4-2. With a style that does not define `\url`, such as plain or unsrt, load the `url` or `hyperref` package.

The repository's GitHub page gives the same reference in APA and BibTeX, under **Cite this repository**. It comes from the repository's `CITATION.cff` file.
