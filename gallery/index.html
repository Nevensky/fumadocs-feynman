Feynman diagrams as code blocks

Write a diagram in a ```feynman block, the way fumadocs uses Mermaid. The remark plugin hands it to a server component that emits static SVG at build time, in the EPP primer’s colours, following the site’s light and dark theme. No layout engine and no client JavaScript.

Playground

    Coordinates and curvature

    Positions are (x, y) in units of 40 px, with y pointing up. The main line of a diagram sits on y = 0, where an equation sets its = and + signs. Here a and b are on that line, 2.8 units apart. A line that says grid draws this grid and the vertex names while you draft.

    above and below name a side of the page, whatever order the ends are written in. On a straight line they place the label ("G" below); on an arc they say which way it bulges; on a loop, where it goes. The arrow never changes the shape.

    bulge=1.2 above gives the height of the arc in the same units as the positions, so it stays 1.2 when a vertex moves. arc above is a half circle.

    grid
a at (0, 0) disk; b at (2.8, 0) disk
leg a left; leg b right
b -> a fermion dressed "G" below
a -- b phonon dressed bulge=1.2 above "F"

    The older bend=0.42 gives the height as a fraction of the distance between the ends (0.42 × 2.8 ≈ 1.18 units). Without a page word, its sign counts from the written direction: positive bulges to the left of a → b.

    Vertex corrections

    First order: a phonon or W across the vertex

    Left, the electron–photon vertex dressed by a phonon; right, the Coulomb vertex dressed by W. Migdal’s theorem, which makes phonon vertex corrections small, holds at large momentum transfer (v_F q ≫ ω); a photon brings q ≈ 0, where it fails. There the Ward identity fixes the charge vertex, Γ = 1 + λ, as large as the self-energy’s renormalization, but not the current vertex a photon couples to: its phonon correction carries the cosine of the scattering angle, vanishes for isotropic coupling, and in transport turns the quasiparticle lifetime into the transport one.
